FAQ

Berapa lama proses top up?

Umumnya beberapa menit setelah pembayaran terkonfirmasi. Saat ramai, bisa sedikit lebih lama.

Apakah perlu password akun game?

Tidak. Kami hanya membutuhkan ID akun (dan Server ID bila ada). Jangan pernah membagikan password kepada siapa pun.

Salah memasukkan ID, bagaimana?

Periksa kembali ID sebelum mengirim pesanan. Pesanan dengan ID yang salah tidak dapat dibatalkan setelah diproses.

Metode pembayaran apa saja?
